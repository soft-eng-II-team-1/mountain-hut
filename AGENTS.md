## Coding Guidelines

1. **Plan before editing:** Briefly explain the intended changes before modifying files. For trivial changes, a one-sentence explanation is sufficient.

2. **Prefer existing abstractions:** Reuse existing helpers, hooks, utilities, and patterns in `src/` before introducing new abstractions. Avoid unnecessary duplication.

3. **Keep changes focused:** Make the smallest reasonable changes needed to fulfill the request. Avoid unrelated refactoring, formatting changes, or modifications to unrelated files.

4. **Follow project conventions:** Match the existing code style, naming conventions, architecture, and patterns unless explicitly instructed otherwise.
