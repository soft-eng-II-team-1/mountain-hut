## Project Structure
- `/backend` — Node.js, Express, TypeScript, SQLite, and Nodemailer API server
- `/frontend` — React + TypeScript (Vite) client application

## Getting Started

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```
