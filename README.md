## Project Structure
- `/backend` — Node.js, Express, TypeScript and Nodemailer API server
- `/frontend` — React + TypeScript (Vite) client application

## Getting Started

### 1. Backend
```bash
cd backend
npm install
npm run dev
```

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```

### 3. Testing

#### 3.1 Unit Tests
```bash
cd backend
npm run test:unit
```

#### 3.2 Integration Tests
```bash
cd backend
npm run test:integration
```

#### 3.3 Full Test Suite
```bash
cd backend
npm run test
```
